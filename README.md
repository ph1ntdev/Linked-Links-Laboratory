## Laboratory3.cpp - Исходный код.
Для сохранения в файл result.csv лучшего случая необходимо в 2х бенчмарках изменить передаваемое значение в findNode на 0. А так же раскомментировать строку 116
Если же необходим худший случай, то на n-1 и закомментировать строку 116

## tables.py - Создание таблицю
Эта программа берет файлы с результатом из папок best и worse и ищет среднее арифметическое всех тестов и создает новую таблицу avg.csv

## graphics.py - Создание графиков
Эта программа рисует графики на основе данных из таблицы avg.csv из папок best и worse.
Программу можно запустить 2 способами:
1. Запустить программу и уже после этого ввести в консоль из какой папки брать таблицу avg.csv.
2. Запустить программу и сразу же передать в параметре название той папки, из которой необходимо взять таблицу avg.csv для построения графиков.
